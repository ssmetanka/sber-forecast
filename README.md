## Идея в трёх строках

1. `log y = n + d`: национальная компонента `n` (медиана по МО: сезонность, инфляция, рост онлайн-покупок)
   + локальное отклонение МО `d`.
2. `n` — среднее трёх простых моделей с национальными рядами СберИндекса 2018–2026 (as-of, лаг 1 мес.);
   `d` — ансамбль, отобранный по validation из простых моделей, LightGBM и foundation models (Chronos-2
   совместный и одномерный, Chronos-Bolt base/small, TimesFM-2.5, дообученный Chronos-2); в итоговые веса
   вошли TimesFM-2.5, LightGBM и простые модели. TiRex считается только на GPU (ноутбук Colab) и в отбор
   локального прогона не входит.
3. Шоки ищет BOCPD на `d` при равной частоте ложных тревог; новости о ЧС (ГУ МЧС, акты о режиме ЧС,
   Lenta.ru), привязанные к МО и месяцу публикации, повышают априорную вероятность разрыва.
   Региональные события дополнительно ловит панельный детектор Стауффера.

## Главные результаты

Rolling-origin бэктест: 18 точек прогноза (июнь 2023 – ноябрь 2024), test — цели июля–декабря 2024 г.,
**каждый горизонт проверен на 6 целевых месяцах**; MAE — ₽ на жителя в месяц.

| | h = 1 | h = 3 | h = 6 | h = 12 |
|---|---|---|---|---|
| Ансамбль, вся панель (12 096 рядов) | **325** | **426** | **525** | **518** |
| Лучшая одиночная модель — TimesFM-2.5 на отклонении МО | 326 | 424 | 527 | 575 |
| Против лучшей из трёх конфигураций Prophet, выбранной задним числом по test | **−29 %** | **−28 %** | **−27 %** | **−51 %** |
| Против Prophet по умолчанию на всей панели (12 096 рядов) | −49 % | −41 % | −30 % | −50 % |

95 %-интервалы разницы (двусторонний бутстреп по МО и месяцам) не накрывают ноль ни на одном горизонте;
ансамбль лучше во всех 6 из 6 целевых месяцев на каждом горизонте (знаковый тест p = 0,031).
Внешняя проверка на 2025 г.: прогноз роста «Всех категорий» +14,9 % против факта портала +14,1 %.

**Детекция:** рабочий детектор — BOCPD на отклонении МО с новостным hazard; полнота 0,27 при 3 ложных
тревогах на 100 ряд-месяцев по всей сетке 3–20 % (случайный ориентир 0,09), лучший из 12 при любой величине
и охвате шока; **на шоках 10–20 % — 0,43**, на ступеньках 5–20 % — 0,39 (сопоставимые постановки — в
[`RESULTS.md`](RESULTS.md));
на паводке 2024 г. тревоги в МО из сообщений о ЧС в 2,36 раза чаще фона (p = 0,008; 2,39×, p = 0,007, если hazard строить без новостей, задающих группу); эффект проверен не только на паводке — см. event study по **361 ЧС** ниже.
**Новости:** Lenta.ru + ГУ МЧС + акты о режиме ЧС, геопривязка к МО через справочник СберИндекса,
дата публикации (as-of), ручной аудит — 90 % событий размечены полностью верно.
В прогоне на GPU (Colab T4) новости ГУ МЧС собраны по **52 регионам**: event study по **361 ЧС** в 56 регионах —
в целом ЧС расходы не меняет, но **маркетплейсы (+0,20σ, p < 0,001) и общепит (+0,10σ, p = 0,006)** реагируют;
оба эффекта значимы с поправкой Бонферрони на 6 категорий ([`RESULTS.md`](RESULTS.md), §3).

## Запуск

```bash
python -m venv .venv
.venv/Scripts/activate            # Windows;  source .venv/bin/activate — Linux/macOS
pip install -r requirements.txt   # точные версии окружения — requirements-lock.txt
python run_all.py                 # весь расчёт (CPU: ≈4–5 ч на 16 ядрах; GPU ускоряет foundation models)
python run_all.py --from 7        # только оценка, таблицы, графики и лендинг по готовым прогнозам
python -m pytest tests -q         # 20 тестов: заглядывание в будущее и компоненты
python tools/quick_check.py       # пересчёт главных чисел из сохранённых прогнозов за секунды
python tools/verify_report.py     # сверка чисел отчёта и README с outputs/tables
```

Python 3.12–3.13. На Linux/macOS можно `make all`. Тяжёлые шаги (Prophet, foundation models) сохраняют
результат после каждой точки прогноза и при перезапуске продолжают с места остановки.

| Шаг | Скрипт | Что делает |

| 0 | `00_get_data.py` | датасет конкурса, справочник МО, национальные ряды портала СберИндекса |

## Конфигурации (гиперпараметры)

* `configs/default.yaml` — пути, сетка бэктеста (origin июнь 2023 – ноябрь 2024), validation/test, горизонты, артефакт 2023-04;
* `configs/models.yaml` — LightGBM (две версии), Prophet (три конфигурации), foundation models, ансамбль;
* `configs/detection.yaml` — детекторы, сетка полусинтетики, уровни FAR, рабочий детектор;
* `configs/news.yaml` — источники, правила типов событий, стоп-лист геокодера, as-of, hazard, официальные источники.

## Структура

